# Security and privacy baseline

Do not commit passwords, API keys, service-role credentials, personal complaint records or report photos. All credentials belong in secrets/config outside source control.

All map and directory data sources require provenance and license checks. No exact citizen incident coordinates or identifying metadata are public by default.

Local browser GPS is optional and must be separately confirmed as the incident position. A user must be able to enter a place manually.

Nigeria Data Protection Act 2023 and applicable implementation rules are compliance inputs, not a substitute for legal review. A privacy and retention policy is required before accepting live reports.

Never claim that a government office viewed or acknowledged a report without verified access evidence.

No live emergency dispatch exists until explicitly integrated with an authorized response agency.
