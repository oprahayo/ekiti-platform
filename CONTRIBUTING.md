# Contributing

This project aims to be open source, but the code license is **not selected yet**. Please open an issue before contributing substantive third-party code until a license and contributor policy are approved.

For discussions and corrections, include the source and effective date for any proposed place or ward data. Do not invent geographic coordinates, use unverifiable business records, or submit private citizen information.

To test locally, use Node 22.16+ and run `npm test`, then `npm run check` with TypeScript installed.

Our first contribution priorities: geographic data-source audits, accessibility review, mobile performance and audited ward-name reconciliation.
